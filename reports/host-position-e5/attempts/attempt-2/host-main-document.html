What the editor does

Everything you need to turn rough text into publishable HTML

phphtmledit.com is a free online HTML editor for content editors, bloggers, marketers and developers. It pairs a rich-text WYSIWYG surface with a real source-code view, so you can work the way that suits the task: drag a heading into place visually, then tighten the markup by hand.

WYSIWYG and source code, side by side

Two synchronised panes in one window. Type formatted text on the left and the HTML on the right updates as you go; change a tag or attribute in the code and the preview follows. No switching modes, no guessing what a button did to your markup.

One-click code cleanup

Strip inline styles, empty tags, editor-specific classes, <span> soup and conditional comments. Choose what to remove, keep the semantic tags, and get markup that passes review.

Paste from Word without the mess

Word and Google Docs carry hundreds of lines of styling into a normal paste. The editor keeps the structure — headings, lists, tables, links — and drops the rest, so a two-page document becomes a few dozen lines of HTML.

Open .html and .docx files

Load a saved page or a Word document straight from your computer — drag the file onto the editor or pick it from the toolbar. The document is parsed locally in your browser, so even large files open instantly.

Export to HTML or DOCX

Copy the code to the clipboard, download a ready .html file, or convert the other way and save the result as a Word document for a colleague to review.

Undo history you can trust

Every change — visual edit, code edit or cleanup pass — goes onto one undo stack. Step back and forward with Ctrl+Z / Ctrl+Y without the two panes falling out of sync.

No account, no uploads

There is nothing to sign up for. The editor loads once and then runs entirely in your browser, which means confidential drafts, client copy and internal documents never leave your machine.

Readable, indented output

The code pane formats as you work: consistent indentation, one block element per line, wrapped attributes. Paste it into a template and the diff stays reviewable.

Step-by-step guide

How to edit HTML online in four steps

The workflow below covers the most common job: taking a Word document or a block of formatted text and turning it into clean HTML ready for a CMS.

1

Load your content into the editor

Open the editor above and paste your text with Ctrl+V, or use Open file to load an .html or .docx document from your computer. Starting from scratch works too — just type in the left pane.

2

Edit visually, or in the code

Use the toolbar for headings, bold, lists, links, tables and images. When you need precision — an attribute, a class, a stray <div> — type it in the code pane instead. Both panes always describe the same document.

3

Run the cleanup pass

Open Clean code, tick what should go — inline styles, empty tags, editor classes, comments — and apply. Review the result in the code pane; if the cleanup went too far, one undo brings the previous version back.

4

Copy the HTML or export a file

Select all in the code pane and copy, or use Download to save an .html file. Need it back in Word? Export to .docx and the headings, lists and tables come across intact.

FAQ

Questions people ask before they start

Something missing? Write to hello@phphtmledit.com and we will add it here.

Is the editor really free?

Yes. Every function on this page — the WYSIWYG pane, the code pane, cleanup, file import and export — is free to use with no limits on how many documents you edit. There is no trial period and no paid tier hiding the useful features.

Do I need to register?

No account, no email, no cookie wall. Open the page and start typing. Your editor preferences are remembered locally in your browser, so the layout you set stays the same next visit.

Is my document uploaded to a server?

No. Parsing, editing, cleanup and export all run in your browser. The page loads its own code once and then works offline as far as your content is concerned — nothing you paste or open is transmitted anywhere, which makes it safe for NDA material and internal drafts.

How do I paste from Word without the extra markup?

Paste as usual, then run Clean code — it removes mso- styles, MsoNormal classes, conditional comments and empty spans while keeping headings, lists, tables and links. If you want plain text with no formatting at all, paste with Ctrl+Shift+V instead.

Is there a limit on document size?

There is no server-side quota, so the practical limit is your own machine. Documents up to a few hundred kilobytes of HTML — roughly a hundred printed pages — stay comfortable. Very large files with many embedded base64 images are the slow case; splitting them into sections keeps typing responsive.

Does it work on a phone or tablet?

It runs in any modern mobile browser — Safari, Chrome, Firefox — with the two panes stacked instead of side by side. Quick fixes and proofreading work well on a tablet; for a long editing session a desktop screen is still the better place to be.

A free HTML editor for everyday content work

Most content does not start life as HTML. It arrives as a Word file from a client, a Google Doc from a colleague, or a block of text copied out of an old page. phphtmledit.com exists for that moment in between: an online HTML editor that shows you the visual result and the underlying markup at the same time, so converting a draft into publishable code takes minutes rather than an afternoon of tag hunting.

Because it runs entirely in the browser, there is nothing to install and no environment to configure. Open the page, work, copy the result — the same routine on a work laptop, a borrowed machine or a locked-down corporate desktop.

Who it is for

Content editors preparing articles for a CMS, marketers building email and landing-page copy, support teams writing knowledge-base pages, and developers who need a scratchpad to check what a fragment of markup renders like.
